1 · Image Quality Gate (Binary AI Model)

Every captured frame is screened by the Binary Image Quality AI model before any downstream analysis. Images it predicts Bad are excluded / flagged for manual review; images it predicts Good proceed to the Binary ECD AI model.

2 · ECD Screening

Only images the quality gate predicts Good reach this step. The Binary ECD AI model classifies each as Acceptable or Low ECD directly — this is the model's own fixed decision, not a live threshold you can move; the histogram below plots the real, segmented-cell ECD values for reference against the clinical 1000 cells/mm² cutoff the model was trained on.

Binary ECD AI model decision boundary: 1000 cells/mm² (fixed by training, not adjustable)

3 · Screening Pass Rate by Visit

Share of quality-passing images the Binary ECD AI model classifies as Acceptable at each study visit, for the current filter selection.

4 · Per-Subject Summary

Image counts and pass rate for every subject in the current filter selection. Sort of last resort for spotting subjects worth a closer look.

5 · Regional ECD Map — Baseline vs. Follow-up

Reconstructs the 15-location widefield capture per eye — 1 central, 8 paracentral and 6 peripheral images — as a spatial map, using the three-zone layout from the project's own region diagram (and matching the imaging protocol in Cheong et al., 2025). Box colour is the Binary ECD AI model's Pass/Fail/Excluded call; the number in each box is the real, segmented-cell ECD value, and arrows/deltas compare that real value against the other selected visit — so colour reflects the AI's prediction while every number here is the ground truth. Positions with no captured image for the selected visit are left empty rather than shown as a placeholder.

Assumed location numbering (edit LOCATION_MAP in the script if your capture protocol differs): location 1 = central (blue zone), locations 2–9 = paracentral ring (pink zone), locations 10–15 = peripheral ring (green zone) — kept as three separate regions rather than merged, per the project's region diagram. Filenames only carry a location index, not its physical position, so this mapping is inferred from that layout rather than confirmed against the capture device. The source data also carries cell area, hexagonality (HEX%) and coefficient-of-variation (CV%) per image; only ECD is visualised here.
